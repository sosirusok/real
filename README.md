# 윤슬 항구 (Yunseul Harbor)

브라우저에서 바로 돌아다닐 수 있는 힐링 풍 3D 항구 도시입니다. 생성한 석재·회벽·목재 이미지를
실제 3D 구조에 입히고, 지형, 건물, 나무, 물, 구름, 생물, 소리는 코드로 생성합니다.
블록(복셀)이 아닌 일반 지오메트리에, 마인크래프트 셰이더 팩 특유의 따뜻한 빛과 공기감을
목표로 한 렌더링을 입혔습니다.

`index.html`에 재질 이미지도 포함되어 있습니다. 파일을 브라우저에서 열거나 정적 서버로 실행하세요.
Three.js 0.170.0과 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 실내와 렌더링 개선

- **검은 사각형 수정**: 하늘·안개의 비정상 부동소수점 계산, 풀의 폭이 0인 페이드,
  물 반사의 텍스처 피드백을 수정했습니다. 블룸 이전에 비정상 HDR 값을 걸러내며
  블룸·물 반사·빛줄기를 유지합니다.
- **실제 1층 공간**: 생성된 532채에 두께가 있는 벽, 바닥, 천장, 창문과 입구를 만들었습니다.
  카페 130개, 책방 146개, 갤러리 127개, 주거 공간 129개입니다.
- **상호작용**: 가까운 대상을 보고 E로 문 열기/닫기, 조명 켜기/끄기, 앉기/일어나기.
  닫힌 문·벽·가구와 열린 문의 문짝에 충돌이 있습니다.
- **언덕 출입**: 지형 높이를 따라 실제 계단·참·난간을 만들고 보행 높이를 맞췄습니다.
- **건축·가구**: 돌출 창틀, 둥근 모서리 창과 원뿔 지붕, 출입구 장식, 카페 준비 공간,
  커피 기계, 책장, 주방, 침구, 곡면 가구, 식물, 실내 조명과 그림자.
- **재질·화면**: 생성한 석재·회벽·오크 이미지, 약해진 돌길 줄눈, 색수차 제거.
- **안정성**: 지원되는 HDR/MSAA 조합, 렌더 해상도 상한, 반사 상태 복구,
  컨텍스트 복구, 가까운 실내만 상세하게 불러오는 처리.

## 월드 구성

- **도시**: 격자형 거리와 중앙 운하, 532채의 건물(박공·모임·평지붕, 발코니, 덧창,
  차양, 굴뚝), 분수와 시계탑이 있는 광장, 연못 공원과 정자, 트램이 다니는 해안 산책로, 부두
- **자연**: 해변, 곶 위의 등대, 숲이 덮인 언덕과 빌라, 눈 덮인 먼 산맥, 벚꽃·플라타너스·
  가문비나무·사이프러스·관목, 카메라를 따라다니는 풀밭과 꽃밭
- **물**: 게르스트너 파도, 여러 겹의 잔물결 노멀, 평면 반사, 수심에 따른 투명도와 색,
  해안선 거품, 물밑 커스틱, 분수의 물줄기와 흘러내리는 물막
- **하늘과 빛**: 시간대별 대기 팔레트, 볼류메트릭 적운(레이마칭) 과 땅에 드리우는 구름 그림자,
  태양·달·별, 높이 안개, 화면 공간 빛줄기, 블룸, ACES 톤 매핑과 색 보정
- **움직임**: 바람에 흔들리는 나무·풀·차양·돛, 떨어져 물에 떠가는 벚꽃잎, 선회하는 갈매기,
  다가가면 날아오르는 비둘기, 나비, 비단잉어와 오리, 흔들리는 배와 항해하는 요트, 트램,
  굴뚝 연기, 밤의 반딧불이·가로등·창문 불빛·등대 불빛
- **소리**: 바람, 파도, 분수, 새소리와 갈매기, 밤의 풀벌레, 선택형 잔잔한 음악(Web Audio로 합성)

## 조작

| 방식 | 조작 |
| --- | --- |
| 둘러보기 | 드래그로 회전, 휠로 확대, 오른쪽 드래그로 이동 |
| 걷기 | 화면 클릭 후 마우스로 시점, `W A S D` 이동, `Shift` 달리기, `Space` 점프, `Esc` 해제 |
| 비행 | 화면 클릭 후 `W A S D` 이동, `E`/`Q` 오르내리기, `Shift` 빠르게 |
| 시네마 | 드론처럼 천천히 도시를 한 바퀴 돕니다 |

- `1`–`7`: 항구, 운하, 광장, 공원, 언덕, 등대, 해변 시점으로 이동
- `8`: 실내 골목. 걷기로 바꾸고 문에 다가가 `E`로 들어가세요. 터치에서는 상호작용 안내를 누르세요.
- `V`: 이동 방식 전환, `T`: 시간 흐름 켜고 끄기, `H`: UI 숨기기, `M`: 음악
- 오른쪽 위 설정에서 시각, 구름 양, 바람 세기, 그래픽 품질, 효과를 바꿀 수 있습니다.
- 모바일에서는 왼쪽 아래를 끌어 움직이고 나머지 화면을 밀어 둘러봅니다.

처음 몇 초 동안 프레임이 너무 낮으면 그래픽 품질을 자동으로 한 단계 낮춥니다.

## 구조

```
src/00_core.js        렌더러, 카메라, 공용 유니폼, 난수·노이즈
src/01_shaderlib.js   재질 패치 시스템(높이 안개, 구름 그림자, 훅), 지오메트리 빌더
src/02_textures.js    절차적 텍스처(노이즈, 물결, 3D 구름, 돌길, 나무껍질, 잎, 꽃)
src/03_terrain.js     지형 높이, 표면 마스크, LOD 지형 청크, 먼 산맥
src/04_sky.js         하늘, 구름 레이마칭, 태양/달, 환경광
src/05_water.js       물 재질, 평면 반사
src/06_post.js        빛줄기, 블룸, 톤 매핑, 색 보정
src/07_controls.js    카메라 모드와 시점 이동
src/08_citymats.js    외벽(내부 매핑 창문)·지붕·석재·포장·소품 재질
src/09_city.js        거리, 운하, 다리, 건물 생성, 보행 격자
src/10_landmarks.js   광장, 공원, 부두, 등대, 언덕 마을, 해변 오두막
src/11_nature.js      나무 생성과 인스턴싱, 풀·꽃 필드
src/12_life.js        생물, 배, 트램, 입자, 조명
src/13_ui.js          UI 연결
src/14_audio.js       사운드스케이프
src/15_interiors.js   실제 1층 구조·가구·문·충돌·상호작용
src/template.html     페이지 뼈대와 스타일
tools/build.mjs       src를 하나로 묶어 index.html 생성
```

수정 후에는 다음으로 다시 빌드합니다.

```
node tools/build.mjs
```

충돌 검사: `node tools/test-interiors.cjs`.
반사 상태 검사: `npm install --no-save three@0.170.0` 후 `node tools/test-render-state.mjs`.
`THREE_MODULE`로 검사에 사용할 Three.js 모듈 경로를 지정할 수도 있습니다.

재질은 `assets/materials/`의 웹용 JPEG이며, 생성 도구와 실제 프롬프트는
`assets/materials/material-prompts.md`에 기록했습니다. 측정한 PBR 스캔 자료가 아닌
생성된 색상 이미지입니다. 원본 PNG는 이미지 생성 결과물에 보관합니다.

## 구현 범위

실내 이동은 **1층**입니다. 상층은 외관용 구조이며 계단이나 상층 방은 구현하지 않았습니다.
사진 실사 또는 GTA·배틀그라운드급 자산 품질을 보장하지 않습니다.
파도·바람·빛은 시각적 시뮬레이션으로, 과학 실험용 정확도를 검증한 모델이 아닙니다.
기기 성능과 해상도에 따라 프레임 속도가 달라집니다.
